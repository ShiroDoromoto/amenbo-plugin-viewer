# spec — 契約

4つの部品が共有する取り決めを置く。**契約が変わると4部品とも変わる**ので、
どの部品の下にもぶら下げず、ここを唯一の参照先にする。

| 決めるもの | 効く先 |
|---|---|
| スナップショットの形式（版番号を含む） | プラグイン・アプリ |
| 暗号の方式と鍵長 | プラグイン・アプリ |
| QR に載せるもの | プラグイン・アプリ |
| エンドポイントの仕様（`PUT /records` ／ `GET /records` ／ `GET /meta` ／ `PUT /reset`） | プラグイン・Worker・アプリ |

**まだ空である。** 中身は本体側で運ぶ物が決まってから書く。
