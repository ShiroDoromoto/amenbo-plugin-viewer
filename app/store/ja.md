# 日本語 (ja)

## name

amenbo Viewer

## subtitle

PC のバックログを、手元で

## short

PC に置いてある amenbo のバックログを、電話で読む。暗号のまま届き、書き戻さない。

## keywords

amenbo,バックログ,タスク,決定記録,AI,エージェント,ビューア,オフライン,同期,cloudflare

## description

amenbo Viewer は、PC に置いてある amenbo のバックログを電話で読むためのアプリです。読むだけで、書き戻しません。

要るのは、Mac・Windows・Linux のどれかで動いている amenbo と、viewer プラグインです。その PC が無ければ映すものがありません。道具の片割れであって、単体で完結する道具ではありません。

どうやって届くか

- Mac と iPhone: 自分の iCloud を通って届きます。電話側の設定はありません。
- Cloudflare のアカウントがあれば、どちらの電話でも: PC が自分の Worker へ渡し、電話が取りに行きます。組むときは、PC の画面に出たコードにカメラを向けるだけです。

どちらの道も、こちらのサーバーを通りません。アカウントを作る必要もありません。

暗号のまま渡る

ネットワークを流れるのは暗号文です。鍵はコードで一度だけ渡り、通信には出ません。電話の中の写しはいつ消してもかまいません。PC は書き続けているので、失われるものはありません。

読めるもの

- タスクと決定記録、その両方のコメント
- 状態・優先度・期限・プロジェクト・分類
- 全部にまたがる検索。語の間に空白を置かない言語でも引けます
- オフラインでも全部。電話は自分の中の写しを読みます

読むだけ、と決めてあります

ここで何をしてもバックログは変わりません。移動中に読んだものは、PC が書いたままの姿です。タスクは番号・表題・状態の3行だけ、共有シートから外へ出せます。

広告なし。追跡なし。アカウントなし。
