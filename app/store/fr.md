# Français (fr)

## name

Amenbo Viewer

## subtitle

Votre backlog, en poche

## short

Lisez sur le téléphone le backlog Amenbo de votre PC. Chiffré, lecture seule.

## keywords

Amenbo,backlog,tâches,décisions,journal,IA,agent,lecteur,hors ligne,chiffrement,cloudflare

## description

Amenbo Viewer met dans votre poche le backlog que vous tenez sur votre PC. Il le lit ; il n'y écrit jamais.

Il faut qu'Amenbo tourne sur un Mac, un Windows ou un Linux, avec le greffon viewer installé. Sans cette machine, cette application n'a rien à montrer : c'est l'autre moitié d'un outil, pas un outil à elle seule.

PAR OÙ ÇA ARRIVE

Le PC confie le backlog à un worker qui vous appartient, sur votre propre compte Cloudflare, et le téléphone vient le chercher. Pour appairer, visez avec la caméra le code affiché sur l'écran du PC. C'est pareil sur les deux téléphones.

La route ne passe par aucun serveur à nous, et il n'y a pas de compte chez nous à créer.

CHIFFRÉ, ET TOUJOURS À VOUS

Ce qui traverse le réseau est chiffré. La clé, elle, ne traverse qu'une fois, dans le code d'appairage, et jamais sur le fil. Effacez la copie du téléphone quand vous voulez : le PC continue d'écrire, rien n'est perdu.

CE QUE VOUS POUVEZ LIRE

- Les tâches et les décisions, avec les commentaires des deux
- État, priorité, échéances, projets, catégories
- Une recherche sur l'ensemble, y compris dans les langues qui n'espacent pas les mots
- Tout hors ligne : le téléphone lit sa propre copie, pas le réseau

LECTURE SEULE, PAR CHOIX

Rien de ce que vous faites ici ne change le backlog : ce que vous lisez dans le métro est tel que votre machine l'a écrit. Une tâche sort par la feuille de partage en trois lignes — numéro, titre, état — à coller dans ce que vous êtes en train d'écrire.

Pas de publicité. Pas de pistage. Pas de compte.
