# ไทย (th)

## name

Amenbo Viewer

## subtitle

งานค้างของคุณ ในมือถือ

## short

อ่านงานค้าง Amenbo จากพีซีของคุณบนมือถือ เข้ารหัส อ่านอย่างเดียว ไม่ต้องมีบัญชี

## keywords

Amenbo,งานค้าง,งาน,การตัดสินใจ,บันทึก,AI,เอเจนต์,ตัวอ่าน,ออฟไลน์,เข้ารหัส,cloudflare

## description

Amenbo Viewer พางานค้างที่คุณเก็บไว้บนพีซีมาอยู่ในกระเป๋า มันอ่านอย่างเดียว ไม่เคยเขียนกลับ

สิ่งที่ต้องมีคือ Amenbo ที่ทำงานอยู่บน Mac, Windows หรือ Linux พร้อมปลั๊กอิน viewer หากไม่มีเครื่องนั้น แอปนี้ก็ไม่มีอะไรให้แสดง เพราะมันเป็นอีกครึ่งหนึ่งของเครื่องมือ ไม่ใช่เครื่องมือที่สมบูรณ์ในตัวเอง

มาถึงได้อย่างไร

- Mac กับ iPhone: ผ่าน iCloud ของคุณเอง ฝั่งมือถือไม่ต้องตั้งค่าอะไร
- ถ้ามีบัญชี Cloudflare ใช้ได้กับมือถือทั้งสองแบบ: พีซีส่งงานค้างให้ worker ที่เป็นของคุณ แล้วมือถือไปรับมา การจับคู่ทำได้ด้วยการหันกล้องไปที่รหัสบนหน้าจอพีซี

ทั้งสองเส้นทางไม่ผ่านเซิร์ฟเวอร์ของเรา และไม่มีบัญชีให้ต้องสมัคร

เข้ารหัส และยังเป็นของคุณ

สิ่งที่วิ่งผ่านเครือข่ายคือข้อความที่เข้ารหัสแล้ว ส่วนกุญแจข้ามมาครั้งเดียวในรหัสจับคู่ และไม่เคยวิ่งผ่านสาย จะลบสำเนาในมือถือเมื่อไรก็ได้ พีซียังเขียนต่อไป จึงไม่มีอะไรหาย

อ่านอะไรได้บ้าง

- งานและบันทึกการตัดสินใจ พร้อมความคิดเห็นของทั้งสองอย่าง
- สถานะ ความสำคัญ กำหนดส่ง โปรเจกต์ และหมวดหมู่
- ค้นหาได้ทั้งหมด รวมถึงภาษาที่ไม่เว้นวรรคระหว่างคำ
- อ่านได้ครบแม้ออฟไลน์ เพราะมือถืออ่านสำเนาของตัวเอง ไม่ได้อ่านเครือข่าย

อ่านอย่างเดียว โดยตั้งใจ

ไม่ว่าคุณทำอะไรที่นี่ งานค้างก็ไม่เปลี่ยน สิ่งที่อ่านระหว่างทางคือสิ่งที่เครื่องของคุณเขียนไว้พอดี งานหนึ่งชิ้นออกไปทางเมนูแชร์ได้เป็นสามบรรทัด คือหมายเลข ชื่อเรื่อง และสถานะ เอาไปวางในสิ่งที่คุณกำลังเขียนอยู่

ไม่มีโฆษณา ไม่มีการติดตาม ไม่มีบัญชี

- ถ้าสำเนาฝั่งคอมพิวเตอร์ถูกสร้างขึ้นใหม่ทั้งหมด จะบอกก่อนอ่านต่อ
- ของที่มาถึง อ่านเฉพาะชื่อที่ข้อตกลงเขียนไว้
